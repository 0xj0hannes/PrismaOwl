Search Strategy

Let the LLM draft database queries from your research question, edit them, then harvest results straight from the databases as BibTeX.

1. Research question

Advanced: rationale & limitations (filled in by the LLM, editable)

2. Concepts & terms

Concepts are combined with AND; terms inside a concept with OR.

3. Database queries

Edit freely, or press Rebuild from concepts to regenerate every query from the concept blocks (AND between concepts, OR inside) without an LLM call; a year range in the scope notes is applied too. Run harvests through the database's official API and saves a .bib file below; databases without an open API show a manual export hint.

4. Harvest runs

Each run stores its hits straight into the corpus (deduplicated against what is already there) together with the query, database, date and year range. Download a run as .bib any time.

Models

Screening is pinned to one concrete model for reproducibility: on OrcaRouter, meta-models such as orcarouter/auto or orcarouter/free are refused for screening (they stay fine for the other tasks).
